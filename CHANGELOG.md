# Changelog

## 1.3.0 – first public release

- **F2** reloads the file from disk, keeping mode and scroll position.
- **Auto-reload** when the file changes on disk (`AutoReload=1`, default; `0` turns it off).

## 1.2.0

- Mode toggle moved to **Ctrl+M**, **Ctrl+Tab** and **Ctrl+U**; single-letter keys
  (S, P, H, N, …) are left to Lister.
- Help page on **F1** (and **?**).

## 1.1.0

- Help page: the README is embedded in the plugin and shown in the viewer.
- Version information resource.

## 1.0.0

- Formatted (RichEdit) and source views of Markdown files: CommonMark core plus GitHub
  extensions (tables, task lists, strikethrough, autolinks), clickable links, dark mode.
- Lister search (F7 / Alt+F7 / Ctrl+F, F3 / Shift+F3), printing, copy, percent display.
